# ПЕРЕХВАТ — 3D-шутер в браузере

Тактический шутер от первого лица, 5 на 5, в духе классических командных шутеров, но со своими правилами.

**Как запустить:** откройте `index.html` в браузере (Chrome, Edge, Firefox). Нужен интернет, чтобы загрузить библиотеку Three.js. Устанавливать ничего не нужно.

## Android (APK)
**Скачать:** [Perehvat.apk](https://github.com/isoft16/claude-helper-/releases/latest/download/Perehvat.apk). Его собирает GitHub Actions при каждом пуше.

1. Скачайте `Perehvat.apk` на телефон и откройте файл.
2. Разрешите установку из неизвестных источников, если телефон спросит.
3. Играйте в горизонтальной ориентации. Интернет не нужен: three.js уже внутри APK.

Сенсорное управление:
- левая часть экрана — джойстик движения;
- правая часть — поворот камеры (можно вести пальцем прямо по кнопке «ОГОНЬ»);
- кнопки: прыжок, присесть, перезарядка, оружие, рывок, граната, прицел, магазин, таблица счёта (☰) и пауза.

Системная кнопка «Назад» ставит игру на паузу.

Собрать APK самостоятельно (Ubuntu):
```bash
sudo apt-get install android-sdk android-sdk-platform-23 dalvik-exchange apksigner zipalign
./android/build.sh        # результат: android/build/Perehvat.apk
```
Приложение — это полноэкранный WebView (`android/src/.../MainActivity.java`). Он отдаёт `index.html` из `assets`. Если ключа подписи `android/perehvat.keystore` нет, скрипт создаст его сам. Ключ не хранится в репозитории, поэтому сборки с разных компьютеров подписаны разными ключами. Если Android откажется ставить новую версию поверх старой, сначала удалите старую.

## Графика и анимация
Все модели собраны в коде из гладких форм: капсул, сфер, скруглённых блоков и выдавленных профилей. Кубиков больше нет.
- **Солдаты:** шлем с очками и гарнитурой, балаклава, плитоноска с подсумками, рюкзак с рацией и антенной, наплечники, наколенники, ботинки, перчатки, камуфляж своей команды.
- **Анимация солдат:** руки и ноги работают через обратную кинематику (IK), то есть суставы рассчитываются по положению ступни или кисти. Солдаты ходят шаговым циклом, держат стрелковую стойку, вздрагивают от попаданий и чувствуют отдачу. Перезарядка идёт со сменой магазина. При смерти тело падает, а оружие выпадает на пол.
- **Оружие от первого лица:** детальные модели (прицелы, планки, цевьё с прорезями, магазины, дульные тормоза) в руках в перчатках.
- **Анимация от первого лица:** пружинная отдача, покачивание при ходьбе, перезарядка со сменой магазина и взводом затвора, помпа дробовика, продольно-скользящий затвор снайперской винтовки, отходящий затвор пистолета, вращение барабана револьвера, удары ножом, осмотр оружия (F) и вылетающие гильзы.
- **Окружение:** отражения на металле, небо-закат со звёздами, неоновая подсветка в цветах команд, скруглённые ящики.

## Чем отличается от классики
- **Узел связи вместо бомбы.** Через 20 секунд после начала раунда в центре карты открывается зона. Если стоять в ней без врагов, шкала перехвата растёт. Заполнили шкалу — раунд ваш. Если в зоне есть враги, шкала замирает.
- **Рывок (E):** короткий бросок в сторону движения, перезарядка 5 секунд.
- **Импульсная граната (G):** отскакивает от стен, взрывается через 1,7 с.
- Своё оружие: «Оса», «Гадюка», «Шершень», «Молот», «Буран», «Игла» (снайперская, с прицелом).
- Симметричная неоновая карта и радар в углу экрана.

## Правила
- Ваша команда «Вектор» (вы и 4 бота) против «Ржавчины» (5 ботов).
- Раунд выигрывает команда, которая уничтожит соперников или перехватит узел. Если время вышло, побеждает тот, у кого больше прогресс перехвата.
- Матч длится до 8 побед. Между раундами есть экономика: деньги за победу, поражение и убийства, оружие покупается в магазине (B).

## Управление
| Клавиша | Действие |
|---|---|
| WASD | движение |
| Shift / C / Пробел | тихий шаг / присесть / прыжок |
| ЛКМ / ПКМ | огонь / снайперский прицел |
| 1, 2, 3, Q | основное, пистолет, нож, прошлое оружие |
| R | перезарядка |
| E | рывок |
| G | граната |
| F | осмотреть оружие |
| B | магазин (покупка клавишами 1–8) |
| Tab | таблица счёта |
| Esc | пауза |

Сложность ботов выбирается в меню: «Новобранцы», «Бойцы» или «Ветераны».
