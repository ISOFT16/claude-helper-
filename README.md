# Умный урок — AI School

Приложение для учеников 5–11 классов: записывает объяснение учителя (с его разрешения),
превращает речь в текст и с помощью ИИ делает конспект, находит домашнее задание,
отвечает на вопросы по уроку, составляет тест и карточки для запоминания.

Работает как веб-приложение (PWA): открывается в браузере телефона и устанавливается на главный экран Android.

## Как запустить на компьютере

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install        # скачать библиотеки (один раз)
npm run build      # собрать приложение
npm start          # запустить сервер
```

Открой в браузере <http://localhost:8787>. Без ключей включится **демо-режим**: все кнопки работают,
но вместо твоей записи подставляется учебный пример урока.

Для разработки удобнее `npm run dev` (адрес <http://localhost:5173>): страница сама обновляется, когда меняешь код.

## Как подключить настоящий ИИ

1. Скопируй файл `.env.example` в `.env`.
2. Впиши ключи (их два — для двух разных задач):
   - `STT_API_KEY` — распознавание речи. Подходит любой сервис, совместимый с OpenAI Whisper API
     (адрес и модель задаются в `STT_BASE_URL` и `STT_MODEL`).
   - `ANTHROPIC_API_KEY` — ИИ Claude пишет конспект, тест, карточки и отвечает в чате.
     Вместо него можно указать `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` для OpenAI-совместимого сервиса.
3. Задай `ACCESS_CODE` (любое слово) и введи его в приложении: Настройки → Сервер → Код доступа.
4. Перезапусти сервер: `npm start`.

> **Важно.** Ключи платные, а аккаунты в таких сервисах обычно можно создавать только взрослым.
> Попроси родителей создать ключи и поставить в кабинете сервиса лимит расходов.
> Урок на 45 минут — это один запрос на распознавание и один запрос к ИИ.

## Как открыть на телефоне

Браузеры разрешают микрофон **только на защищённом адресе (https)** или на `localhost`. Поэтому есть три пути:

| Способ | Что работает |
|---|---|
| Телефон и компьютер в одной сети Wi‑Fi, адрес `http://IP-компьютера:8787` | Всё, кроме записи с микрофона (можно загружать готовые аудиофайлы с диктофона) |
| Телефон подключён по USB, в Chrome на компьютере `chrome://inspect` → Port forwarding `8787` → на телефоне `http://localhost:8787` | Всё, включая микрофон |
| Сервер размещён в интернете на хостинге с https (или открыт через https-туннель) | Всё, включая микрофон и установку на главный экран. Обязательно задай `ACCESS_CODE` |

Чтобы установить: в Chrome на Android открой меню ⋮ → «Добавить на главный экран».

## Как это устроено (простыми словами)

```
Телефон (браузер)                       Сервер (Node.js)                 Сервисы ИИ
┌─────────────────────┐  аудио   ┌──────────────────────────┐  части  ┌──────────────────┐
│ запись с микрофона  │ ───────► │ ffmpeg сжимает и режет   │ ──────► │ распознавание     │
│ экраны, дневник     │          │ запись на части по 10 мин│ ◄────── │ речи (Whisper API)│
│ хранение уроков     │ ◄─────── │ проверяет лимиты и код   │  текст  └──────────────────┘
│ (IndexedDB)         │ конспект │ доступа, хранит ключи    │ ──────► ┌──────────────────┐
└─────────────────────┘          └──────────────────────────┘ ◄────── │ Claude: конспект, │
                                                                       │ тест, карточки    │
                                                                       └──────────────────┘
```

- **`src/`** — само приложение (React + TypeScript): то, что видит ученик.
- **`server/`** — сервер. Только он знает секретные ключи; в браузер они не попадают.
- **`shared/`** — общие описания данных (что такое «конспект», «вопрос теста»).
- **`tests/`**, **`scripts/e2e.mjs`** — автоматические проверки.

Почему нужен сервер? Если положить ключ в код страницы, его сможет увидеть и украсть любой посетитель.

## Что реально работает, а что нет

Проверено автоматически (`npm test` — 5 тестов сервера, `npm run e2e` — 20 проверок в браузере с экраном телефона):

- запись: старт только после галочки «учитель разрешил», пауза, продолжение, завершение, таймер, индикатор микрофона, красная плашка записи на всех экранах;
- сохранение записи каждые 5 секунд и восстановление после закрытия приложения;
- загрузка готового аудиофайла; запись на 61 минуту режется на 7 частей;
- конспект, домашнее задание (с ручным редактированием), чат, тест, карточки, дневник, поиск, «что повторить», расписание, статистика;
- светлая и тёмная темы, русский и казахский языки, установка как PWA;
- удаление аудио после создания конспекта (по умолчанию), удаление всех данных;
- код доступа, дневные лимиты, ограничение длины записи.

Для `npm run e2e` дополнительно нужен Playwright: `npm i -D playwright && npx playwright install chromium`.

Чего **ещё не проверено или нет**:

- **Настоящие ИИ-сервисы не вызывались** — у меня не было ключей. Код для них проверен только на «поддельных» серверах,
  которые отвечают в том же формате. При первом запуске с ключами возможны мелкие правки.
- Качество распознавания речи в шумном классе и на казахском языке не проверялось — оно зависит от выбранного сервиса.
- В демо-режиме «конспект» собирается простыми правилами из учебного примера — это не ИИ.
- Запись идёт, только пока приложение открыто и экран включён (ограничение браузеров). Приложение просит телефон не гасить экран.
- На настоящем телефоне приложение не запускалось — только в эмуляции экрана Pixel 7 в Chromium.
- Нет входа по аккаунту и синхронизации между устройствами: все уроки лежат только в этом телефоне.
- Отдельного Android-приложения (APK) пока нет; его можно будет сделать из этого же кода (например, через Capacitor).

## Приватность и безопасность

- Запись начинается только после явного подтверждения, что учитель разрешил; во время записи всегда виден красный индикатор.
- Аудио отправляется на сервер только для распознавания и сразу удаляется с него (и при успехе, и при ошибке).
- В телефоне аудио удаляется после успешного создания конспекта, если в настройках не включено хранение.
- Конспекты хранятся только на устройстве; кнопка «Удалить все мои данные» стирает всё.
- Приложение ничего не публикует и не передаёт другим ученикам.
- Выбирая сервисы ИИ, проверь вместе с родителями их правила: используются ли данные для обучения моделей и где они хранятся.
  Перед использованием в школе нужно согласие учителя и родителей.
