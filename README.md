# ПЕРЕХВАТ — 3D-шутер в браузере

Тактический шутер от первого лица, 5 на 5, в духе классических командных шутеров, но со своими правилами.

**Как запустить:** откройте `index.html` в браузере (Chrome, Edge, Firefox). Нужен интернет, чтобы загрузить библиотеку Three.js. Устанавливать ничего не нужно.

## Чем отличается от классики
- **Узел связи вместо бомбы.** Через 20 секунд после начала раунда в центре карты открывается зона. Если стоять в ней без врагов, шкала перехвата растёт. Заполнили шкалу — раунд ваш. Если в зоне есть враги, шкала замирает.
- **Рывок (E):** короткий бросок в сторону движения, перезарядка 5 секунд.
- **Импульсная граната (G):** отскакивает от стен, взрывается через 1,7 с.
- Своё оружие: «Оса», «Гадюка», «Шершень», «Молот», «Буран», «Игла» (снайперская, с прицелом).
- Симметричная неоновая карта и радар в углу экрана.

## Правила
- Ваша команда «Вектор» (вы и 4 бота) против «Ржавчины» (5 ботов).
- Раунд выигрывает команда, которая уничтожит соперников или перехватит узел. Если время вышло, побеждает тот, у кого больше прогресс перехвата.
- Матч длится до 8 побед. Между раундами есть экономика: деньги за победу, поражение и убийства, оружие покупается в магазине (B).

## Управление
| Клавиша | Действие |
|---|---|
| WASD | движение |
| Shift / C / Пробел | тихий шаг / присесть / прыжок |
| ЛКМ / ПКМ | огонь / снайперский прицел |
| 1, 2, 3, Q | основное, пистолет, нож, прошлое оружие |
| R | перезарядка |
| E | рывок |
| G | граната |
| B | магазин (покупка клавишами 1–8) |
| Tab | таблица счёта |
| Esc | пауза |

Сложность ботов выбирается в меню: «Новобранцы», «Бойцы» или «Ветераны».
