# VigilBoard — клавиатура в стиле Google Pixel

Настоящая системная клавиатура для Android (ставится вместо Gboard и работает во всех
приложениях). Дизайн — максимально в духе Google Pixel / Gboard, шрифт — официальный
**Google Sans** (лицензия SIL OFL, файл `app/src/main/assets/fonts/OFL.txt`).

> Этот проект живёт на ветке `claude/custom-keyboard-google-pixel-is9w5p`
> (в этом репозитории каждый проект — на своей ветке).

## Возможности

- 🇷🇺🇬🇧 **Русская (ЙЦУКЕН) и английская (QWERTY)** раскладки, переключение глобусом 🌐
  или по надписи РУС/ENG. Две страницы символов `?123` и `=\<`.
- 🌍 **Переводчик прямо с клавиатуры**: кнопка на верхней панели переводит весь набранный
  текст (авто-определение языка → русский или английский). Бесплатно, без ключей.
- 🎙️ **Голосовой ввод**: микрофон на верхней панели, распознавание на текущем языке
  (русском или английском), промежуточный текст виден прямо на панели.
- 🎨 **Кастомизация как хочешь**:
  - темы: как в системе / светлая / тёмная / AMOLED / **Material You** (цвета из обоев, Android 12+);
  - 8 цветов акцента;
  - высота клавиш и скругление углов — ползунками;
  - отдельный ряд цифр, плоский стиль без фона клавиш, подсказки символов;
  - вибрация (с настройкой силы) и звук клавиш.
- ⌨️ Как у Gboard: авто-заглавная буква в начале предложения, Caps Lock двойным тапом
  по Shift, повтор удаления при зажатии ⌫, долгое нажатие — символ из уголка
  (`ё` — на «е», `ъ` — на «ь», цифры — на верхнем ряду), мультитач для быстрой печати.

## Как включить после установки

1. Откройте приложение **VigilBoard**.
2. Кнопка «1. Включить VigilBoard в системе» → включите VigilBoard в списке.
3. Кнопка «2. Выбрать VigilBoard как клавиатуру».
4. Для голосового ввода — кнопка «3. Разрешить микрофон».
5. Проверьте в поле прямо на экране настроек.

## Сборка на своём компьютере

Нужны JDK 17 и Android SDK:

```bash
gradle assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

При каждом push GitHub Actions собирает APK сам (`.github/workflows/build.yml`).

## Как устроено

| Файл | Что делает |
|---|---|
| `VigilImeService.kt` | IME-сервис: ввод, панель перевода, голосовой ввод, вибрация |
| `PixelKeyboardView.kt` | Отрисовка клавиш на Canvas, мультитач, долгие нажатия |
| `Layouts.kt` | Раскладки EN / RU / символы |
| `KbTheme.kt` | Темы Pixel: светлая, тёмная, AMOLED, Material You |
| `Translator.kt` | Перевод через открытую точку Google Translate |
| `SettingsActivity.kt` | Экран настроек и включения |

Иконки — Material Icons (Apache 2.0), шрифт Google Sans — SIL OFL.
