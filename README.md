# Vigil Voice

Приложение для Android, которое позволяет управлять телефоном **только голосом** — для людей,
которые не могут нажимать на экран. Телефон слушает постоянно и выполняет сказанное:
нажимает кнопки, листает, печатает продиктованный текст, открывает приложения, звонит.

Оформление — как у Vigil Browser и Vigil AI: чёрный фон, красные акценты, красная планета на иконке.

## Первая настройка (нужен помощник, один раз)

1. Установите APK и откройте **Vigil Voice**.
2. Шаг 1 — нажмите **«Разрешить»** и согласитесь на микрофон, контакты и звонки.
3. Шаг 2 — нажмите **«Включить»**, в списке специальных возможностей найдите Vigil Voice и включите.
   - На Android 13 и новее переключатель может быть серым («Настройка ограничена»), потому что
     приложение установлено не из магазина. Тогда: **Настройки → Приложения → Vigil Voice → ⋮ →
     «Разрешить ограниченные настройки»**, и повторите шаг.
4. Вверху экрана появится красная точка — телефон слушает. Скажите «домой».

Дальше руки не нужны: после перезагрузки телефона служба запускается сама.

## Что говорить

| Что нужно | Команды |
|---|---|
| Движение | «назад», «домой», «недавние», «вниз», «вверх», «влево», «вправо», «уведомления» |
| Нажать по надписи | «нажми Отправить», «долго нажми Настройки» |
| Нажать что угодно | «цифры» — на всём, что можно нажать, появятся номера → назовите номер. «скрой цифры» |
| Написать текст | «напиши привет запятая как дела» |
| Долгая диктовка | «диктовка» … говорите … «стоп диктовка» |
| Исправить | «сотри» (последнее слово), «сотри всё», «отправь», «ввод» |
| Приложения | «открой Ютуб», «открой настройки», «найди погода завтра» |
| Звонки | «позвони маме», «набери 8 900 …», «ответь», «положи трубку» |
| Звук | «громче», «тише», «без звука», «пауза», «играй», «следующая» |
| Телефон | «скриншот», «заблокируй», «включи экран», «включи фонарик», «который час», «заряд» |
| Пауза | «не слушай» — перестаёт выполнять команды, «проснись» — слушает снова |
| Справка | «помощь» |

Знаки при диктовке: «запятая», «точка», «вопросительный знак», «восклицательный знак»,
«двоеточие», «тире», «новая строка», «новый абзац».

Точка вверху экрана: **красная** — слушает, **жёлтая** — диктовка, **серая** — не слушает.

## Важно знать

- **Телефон слушается любого голоса**, не только владельца. Чтобы он не реагировал на чужие
  разговоры и телевизор, в настройках приложения можно задать слово-обращение (например «телефон»):
  тогда команды надо начинать с него — «телефон, назад».
- **Пароль и PIN голосом не ввести** — экран блокировки с паролем Android посторонним приложениям
  не открывает. Удобнее всего блокировка без пароля или разблокировка по лицу.
- Речь распознаёт система телефона (Google). Если на телефоне скачан русский язык для распознавания
  без интернета, работает и без сети; иначе нужен интернет.
- Некоторые телефоны (Xiaomi, Huawei, Samsung) сами выключают фоновые приложения. Если служба
  перестаёт слушать — отключите для Vigil Voice экономию батареи.
- Постоянное прослушивание расходует заряд быстрее обычного.

## Сборка на своём компьютере

Нужны JDK 17 и Android SDK.

```bash
./gradlew testDebugUnitTest   # тесты разбора команд
./gradlew assembleRelease     # APK: app/build/outputs/apk/release/app-release.apk
```

## Структура

```
app/src/main/java/com/isoft16/vigilvoice/
  Commands.kt      — разбор фразы в команду, числа словами, знаки препинания (без Android, покрыто тестами)
  Listener.kt      — непрерывное распознавание речи
  VoiceService.kt  — служба специальных возможностей: связывает всё вместе и выполняет команды
  Actions.kt       — нажатия, жесты, ввод текста, приложения, звонки, звук
  Overlay.kt       — точка-индикатор, подсказки и номера на кнопках поверх экрана
  MainActivity.kt  — экран настройки и список команд
  Prefs.kt         — настройки
app/src/test/      — тесты
```
