# SandForge — физическая песочница для Android

Своя игра-песочница в духе «строй что хочешь». Есть физика, инструменты, аддоны и мультиплеер.
Все персонажи (роботы-строители), текстуры, карта и названия свои.

## Как скачать APK

1. Откройте вкладку **Releases** этого репозитория, релиз **«SandForge — последняя сборка»**.
2. Скачайте **SandForge.apk** на телефон.
3. Откройте файл и разрешите установку из неизвестных источников, если Android спросит.

APK собирается автоматически (GitHub Actions, файл `.github/workflows/build-apk.yml`) при каждом push.

## Графика

- Физически корректное освещение (PBR): небо с солнцем, освещение и отражения от неба, мягкие тени.
- Постобработка: свечение (bloom), сглаживание, на «Ультра» ещё мягкие тени в углах (GTAO).
- Все материалы свои, генерируются кодом: бетон, плитка, асфальт, трава, доски, кирпич, крашеный и шлифованный металл, резина, пластик, ткань, кора.
  Текстуры и модели из других игр не используются.
- Скруглённые модели без острых углов: ящики с рамой и распорками, рифлёные бочки, дорожные конусы, колёса с шинами, манекены для краш-тестов.
- Карта: кирпичный ангар со стёклами, деревья, холмы на горизонте, фонари, перила.
- Качество: Низкая / Средняя / Высокая (по умолчанию) / Ультра. Меняется в настройках.
- Шрифт интерфейса: Google Font «Exo 2» (лицензия OFL), встроен в игру.

## Что есть в игре

- **Физпушка**: хватайте предметы, носите, вращайте, приближайте/отдаляйте, замораживайте в воздухе.
- **Тулган** с режимами: Удалитель, Сварка, Верёвка, Шарики, Краска, Заморозка, Динамит, Ускоритель.
- **Бластер** и **гранатомёт**: взрывные бочки, разлёт предметов.
- **Меню спавна**: ящики, бочки, мячи, доски, балки, стены, батут, мебель, динамит, ракеты…
- **Персонажи**: робот-манекен (рэгдолл на шарнирах) и бот-бродяга, который ходит по карте и падает рэгдоллом.
- **Полёт (noclip)**, отмена (undo), очистка карты, чат и команды (`!помощь`, `!сохранить`, `!загрузить`, `!очистить`).
- **Карта**: ангар с лестницей на крышу, пандусы, платформы и башня.
- Управление: сенсорное (джойстик + кнопки) или клавиатура/мышь. Держа «Огонь», «Альт» или другую кнопку, можно вести тем же пальцем и поворачивать камеру.

## Скорость: физика на Rust

- Физика (столкновения, рэгдоллы, сварки, взрывы) считается ядром на **Rust**: папка `physics/`, движок Rapier, скомпилирован в WebAssembly и встроен в APK.
- На 150 ящиках это примерно в 4 раза быстрее прежней JS-физики: 1,1 мс против 4,7 мс на шаг, худший шаг 4,8 мс против 20,7 мс.
- Если WebAssembly недоступен, игра сама использует старую физику. Переключатель есть в «Меню разработчика» → «Отладка».
- Отрисовка тоже ускорена:
  - статичная карта склеена в несколько объектов;
  - детали предметов склеиваются по материалу (draw calls: 165 → 95);
  - разрешение само снижается, когда FPS падает ниже 40, и возвращается обратно.
- Реалистичность: облака, трава с ветром, цветокоррекция.

Сборка ядра: `cd physics && cargo build --release --target wasm32-unknown-unknown` (нужна цель `rustup target add wasm32-unknown-unknown`).

## Персонаж и меню разработчика

- **Персонаж** (главное меню или пауза): «примерочная» с 3D-предпросмотром, персонажа можно крутить пальцем.
  - Тело: рост, ширина, размер головы, длина рук и ног, цвет кожи.
  - Одежда: футболка (цвет, узор или своя картинка), штаны, обувь.
  - Лицо: глаза, рот, румянец.
  - Голова: причёски, шапки, шлем, цилиндр, ковбойская шляпа, корона.
  - Аксессуары: очки, наушники, рюкзак, плащ, галстук, шарф.
  - Друзья в мультиплеере видят ваш облик.
- **Вид от третьего лица:** кнопка «Вид» или клавиша F.
- **Меню разработчика** (пауза, защищено PIN-кодом):
  - мир: гравитация, время суток, туман, замедление времени;
  - игрок: скорость бега, прыжок, полёт;
  - объект под прицелом: дублировать, заморозить, масса, подбросить, невесомость, удалить;
  - «дождь» из предметов, очистка карты, счётчик FPS.
  - В мультиплеере мир меняет только хост.
- **Свои картинки на физпушку и на ботов** ставятся в «Настройках» и хранятся только на устройстве.

## Клавиатура и мышь на телефоне

Подключите к телефону клавиатуру и мышь по Bluetooth или через USB-OTG переходник.
- Игра сама переходит в режим «как на ПК», когда двигается мышь или нажимается клавиша: экранные кнопки прячутся.
- Нажмите мышью на экран: курсор захватывается, мышь крутит камеру. Esc отпускает мышь и ставит паузу.
- Управление: WASD, пробел, Shift, ЛКМ/ПКМ, колесо, цифры 1–5, E, Q, Z, V, F, T.
- Клавиши работают по физическому положению, в том числе с русской раскладкой.
- Коснитесь экрана пальцем, и вернётся сенсорное управление. Режим можно закрепить в «Настройках» → «Управление».
- Захват мыши работает на Android 8.0 и новее.

## Мультиплеер

- «Создать сервер»: игра выдаёт **код комнаты** из 5 символов.
- Друзья вводят код в главном меню и нажимают **«Подключиться»**.
- Одиночную игру можно в любой момент открыть для друзей: **Пауза → «Открыть сервер для друзей»**.
- Связь идёт напрямую между телефонами через WebRTC. Для поиска друг друга используется бесплатный сервер PeerJS.
  В настройках можно указать свой сервер PeerJS, например для игры по локальной сети.
- Аддоны хоста автоматически загружаются у подключившихся игроков. Это можно отключить в настройках.

> На некоторых мобильных сетях (строгий NAT у оператора) прямое соединение может не установиться. Тогда попробуйте Wi‑Fi.

## Аддоны

Меню: **Аддоны** →
- **Мастерская**: 6 готовых аддонов (Мебель+, Лунная гравитация, Прыгучие мячи, Гравимагнит, Фейерверки, Пушка предметов);
- **Установить свой**: из файла `.js`, по ссылке или вставив код.

Аддон — это JavaScript-файл:

```js
addon({
  name: 'Мой аддон',
  author: 'Я',
  version: '1.0',
  init(api) {
    // новый предмет
    api.registerProp('my_cube', {
      name: 'Мой куб', icon: '🟪', category: 'Мои вещи', mass: 10,
      shape: { type: 'box', size: [1, 1, 1], color: 0xaa44ff, tex: 'metal' },
    });
    // новый режим тулгана (выполняется на хосте)
    api.registerTool('jump', {
      name: 'Подброс', desc: 'Подбрасывает предмет',
      onPrimary(ctx) {
        if (ctx.ent) ctx.ent.parts[0].body.velocity.y += 10;
      },
    });
    // команда чата !привет и кнопка в «Утилитах»
    api.registerCommand('привет', (pid) => api.chat('Привет всем!'));
    api.registerUtility('👋 Привет', 'привет');
  },
});
```

Примеры лежат в папке [`web/addons/`](web/addons).

**Формы**: `box` (`size: [x, y, z]`), `sphere` (`r`), `cylinder` (`r` или `rt`/`rb`, `h`).
Параметры формы: `offset`, `rot`, `color`, `tex`, `emissive`, `metal`, `tint: false`.
**Текстуры**: `wood`, `plank`, `metal`, `concrete`, `wall`, `stripes`, `hazard`, `checker`, `floor`.
**Свойства предмета**: `mass`, `bouncy`, `health`, `explosive: { radius, force, damage }`, `lift`, `fuse`, `think(ent, dt, api)`, `onDeath`, `parts` + `joints` (для рэгдоллов).
**API**: `spawn`, `remove`, `fx`, `explode`, `weld`, `setColor`, `setFrozen`, `setGravity`, `chat`, `tell`, `ents`, `players`, `on`, `THREE`, `CANNON`.

⚠️ Аддоны — это код. Устанавливайте их только из источников, которым доверяете.

## Сборка самому

```bash
cd physics && cargo build --release --target wasm32-unknown-unknown   # физика на Rust
cd ../web && npm install && npm run build   # игра -> android/app/src/main/assets/www
cd ../android && gradle assembleRelease  # нужен Android SDK (ANDROID_HOME)
```

Для проверки в браузере: откройте `web/dist/index.html`.

Подпись APK: в репозитории лежит **публичный тестовый ключ** `android/sandforge.keystore` (пароль `sandforge`).
С ним новые версии ставятся поверх старых. Для публикации в Google Play сделайте свой закрытый ключ.

## Устройство проекта

- `web/src/`: игра (Three.js для графики, cannon-es для физики, PeerJS для сети).
  - `main.js`: игровой цикл, оружие, сеть; `entities.js`: предметы, сварки, верёвки, взрывы;
  - `content.js`: встроенные предметы и инструменты; `addons.js`: система аддонов;
  - `player.js`: игрок и модели роботов; `world.js`: карта, текстуры, эффекты, звуки;
  - `ui.js`, `controls.js`: интерфейс и управление; `net.js`: мультиплеер.
- `android/`: приложение-оболочка (полноэкранный WebView).
