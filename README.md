# Vigil Launcher

Лаунчер (главный экран) для Android в стиле Pixel Launcher: чистый рабочий стол, круглые иконки,
строка поиска внизу, меню приложений по свайпу вверх и цвета Material You, которые подстраиваются
под обои. Написан на Kotlin без сторонних библиотек, работает на Android 8.0 и новее.

## Возможности

- 🏠 Рабочий стол из нескольких экранов с сеткой 4×5 (или 5×5), листается влево-вправо, обои
  прокручиваются вместе с экранами.
- 📅 Дата в левом верхнем углу первого экрана; нажатие открывает календарь.
- ⚓ Док-панель с избранными приложениями и строка поиска под ней.
- 🗂️ Меню всех приложений: свайп вверх по главному экрану, список по алфавиту, поиск по названию
  и поиск в интернете.
- ✋ Долгое нажатие на иконку: быстрые действия приложения, «О приложении», «Удалить»,
  «Убрать с главного экрана» / «Добавить на главный экран».
- ↔️ Перетаскивание иконок между ячейками, экранами и доком; у края экрана иконка перелистывает
  на соседний экран, на занятой ячейке ярлыки меняются местами.
- 🎨 Цвета Material You из обоев (Android 12+), светлая и тёмная тема.
- 🖼️ Значки: любая форма (круг, сквиркл, скруглённый квадрат, квадрат), три размера,
  тематические одноцветные значки (Android 13+) — в том числе для приложений, у которых своего
  тематического значка нет: он создаётся автоматически, как в новых версиях Pixel.
- 📦 Наборы значков: поддерживается любой установленный набор в общепринятом формате
  (ADW / Nova, файл `appfilter.xml`) — выбирается в настройках лаунчера.
- ✨ Анимации: значки слетаются на места после разблокировки и при возврате из приложения,
  приложение раскрывается из значка, значок пружинит при нажатии, меню вырастает из точки касания.
- 👇 Свайп вниз по главному экрану открывает шторку уведомлений.
- ⚙️ Долгое нажатие на пустом месте: «Обои и стиль» и «Настройки лаунчера» (значки, сетка,
  подписи, анимации).

Анимацию «окно приложения сворачивается в значок» Android разрешает только системному лаунчеру,
поэтому здесь её заменяет анимация значков.

Пока нет: виджетов, папок, значков уведомлений на иконках и рабочего профиля.

## Скачать

Готовый APK после каждой сборки лежит в разделе **Releases** → **Vigil Launcher (последняя сборка)**
→ файл `VigilLauncher.apk`. Сборку делает GitHub Actions (`.github/workflows/build.yml`).

После установки откройте Vigil Launcher и нажмите «Сделать Vigil Launcher главным экраном»
(или выберите его в Настройки → Приложения → Приложения по умолчанию → Главный экран).

## Как собрать самому

Нужны JDK 17 и Android SDK (платформа 35).

```bash
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

## Структура

```
app/src/main/kotlin/com/isoft16/vigillauncher/
  LauncherActivity.kt — главный экран: раскладка, меню, перетаскивание
  HomeRoot.kt         — жесты главного экрана
  AllAppsSheet.kt     — меню всех приложений с поиском
  SettingsActivity.kt — экран настроек лаунчера
  Views.kt            — иконка, сетка, экраны, индикатор, всплывающее меню
  HomeStore.kt        — хранение раскладки
  Apps.kt             — список приложений, отрисовка значков, наборы значков
  Core.kt             — цвета, шрифты, настройки
```

## Подпись

APK подписывается ключом `keystore/vigil-launcher.jks`, который лежит в репозитории. Это сделано,
чтобы новые сборки ставились поверх старых без удаления приложения. Ключ не секретный: если
репозиторий публичный, для распространения приложения другим людям его стоит заменить на личный.
